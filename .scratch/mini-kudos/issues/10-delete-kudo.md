# 10: Kudo 삭제

**What to build:** Author가 쿠도 카드 메뉴에서 "삭제"를 고르면 비밀번호를 묻는 확인 창이 뜬다. 비밀번호가 맞으면 카드가 목록에서 바로 사라지고, 그 Kudo에 달린 Reaction도 함께 지워진다.

**Blocked by:** 06 (Reaction 토글)

**Status:** resolved

- [ ] DELETE 삭제: 올바른 비밀번호면 204이고, 이후 목록에서 사라진다(하드 삭제)
- [ ] 삭제된 Kudo의 Reaction도 함께 사라진다(Board 통계의 reactionCount로 확인)
- [ ] 틀린 비밀번호는 403 `INVALID_PASSWORD`, 없는 id는 404 `NOT_FOUND`다
- [ ] 카드 메뉴(⋯)에 삭제 항목이 있고, 비밀번호를 받는 확인 창이 뜬다
- [ ] 삭제 성공 시 캐시에서 카드를 제거하고 Board 통계를 다시 불러온다
- [ ] 비밀번호가 틀리면 "비밀번호가 일치하지 않습니다" 토스트가 뜨고 창은 열린 채로 남는다
- [ ] Route Handler 테스트가 204·403·404와 Reaction 연쇄 삭제를 검증한다
- [ ] 수동 확인: 삭제 후 새로고침해도 카드가 없다
