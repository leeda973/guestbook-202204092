# 04: 무한 스크롤

**What to build:** Visitor가 목록 끝까지 스크롤하면 다음 Kudo 20개가 자동으로 이어서 불러와진다. 더 불러올 Kudo가 없으면 목록 끝에 도달했다는 표시가 나온다.

**Blocked by:** 03 (Kudo 작성하고 최신순 목록에서 보기)

**Status:** resolved

- [ ] GET 목록 응답에 `nextCursor`가 포함된다. 최신순 커서는 마지막 항목의 id이고, 더 없으면 null이다
- [ ] `cursor`를 넘기면 그보다 오래된 Kudo 20개를 돌려준다
- [ ] 여러 페이지를 이어 받아도 중복·누락이 없다(테스트: 45개를 넣고 3페이지로 모두 받기)
- [ ] 해석할 수 없는 커서는 400 `VALIDATION_FAILED`다
- [ ] 목록 끝의 감지 요소가 화면에 보이면 다음 페이지를 불러온다
- [ ] 다음 페이지를 불러오는 중에는 로딩 표시가, 끝에서는 "모든 Kudo를 다 봤어요" 같은 끝 표시가 보인다
- [ ] 수동 확인: 시드 없이 30개 이상 작성 후 스크롤해 이어 불러오기
