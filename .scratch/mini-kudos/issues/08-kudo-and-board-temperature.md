# 08: 쿠도 온도와 보드 온도

**What to build:** 쿠도 카드마다 Kudo Temperature 배지(예: 38.0°)가, 헤더에 Board Temperature(예: "우리 보드 온도 41.3°")가 보인다. 온도 구간에 따라 배지 색이 초록→주황→빨강으로 바뀌고, Reaction을 누르거나 Kudo를 작성하면 온도가 갱신된다.

**Blocked by:** 06 (Reaction 토글)

**Status:** resolved

- [ ] 온도 계산은 순수 함수 하나에 있다. Kudo = min(99.9, 36.5 + 0.5 × 리액션 수), Board = min(99.9, 36.5 + 0.1 × 전체 리액션 + 0.2 × 전체 Kudo), 소수 첫째 자리 반올림
- [ ] 색 구간: 40.0° 미만 초록, 40.0° 이상 50.0° 미만 주황, 50.0° 이상 빨강
- [ ] 온도 함수 단위 테스트가 공식, 99.9° 상한, 반올림, 구간 경계값(39.9 / 40.0 / 49.9 / 50.0)을 독립적인 기대값으로 검증한다
- [ ] KudoView와 Reaction 응답의 `temperature`가 채워진다
- [ ] GET Board 통계가 `{ kudoCount, reactionCount, temperature }`를 돌려주며, Route Handler 테스트가 실제 데이터와 일치하는지 검증한다
- [ ] Reaction 낙관적 갱신 시 같은 온도 함수로 카드 온도도 즉시 바뀐다
- [ ] Reaction 성공, Kudo 작성 후 헤더의 Board Temperature를 다시 불러온다
- [ ] 수동 확인: 리액션을 여러 번 눌러 배지 색이 구간에 맞게 바뀐다

## Comments
