# 03: 작성 시각을 한국 시간으로 함께 표시

**What to build:** Visitor가 각 쿠도 카드에서 "3분 전 · 9월 30일 14:05"처럼 상대 시간과 정확한 작성 시각을 함께 본다. 정확한 시각은 서버 위치와 상관없이 한국 시간이며, 올해가 아닌 글은 연도도 보인다. 새로고침해도 표기가 바뀌지 않고, 좁은 카드에서도 자연스럽게 줄바꿈된다.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [ ] 작성 시각 포맷 순수 함수(작성 시각, 기준 시각 → 문자열): Asia/Seoul 고정, 올해면 "M월 D일 HH:mm", 아니면 "YYYY년 M월 D일 HH:mm"(24시간제)
- [ ] 순수 함수 단위 테스트(직접 계산한 리터럴): `2026-09-30T05:05:00Z` → "9월 30일 14:05", 한국 날짜로 다음 날이 되는 UTC 시각, 다른 해는 연도 포함
- [ ] 카드 시각 영역이 "{상대 시간} · {정확한 시각}"이고, "(수정됨)"은 뒤에 그대로 붙는다
- [ ] 마우스를 올리면 연도·요일을 포함한 전체 시각이 보인다(한국 시간)
- [ ] 정확한 시각은 서버 렌더와 브라우저가 같은 문자열이다. 하이드레이션 경고 억제는 상대 시간 부분에만 둔다
- [ ] 수동 확인: 데스크톱·모바일 폭에서 카드 머리글 표기

## Comments

- 2026-09-30: 구현 완료. 포맷 순수 함수 테스트 5개(올해 형식, UTC로는 전날인 한국 날짜, 다른 해 연도 포함, 연도를 한국 시간 기준으로 판단, 전체 시각의 연도·요일) 통과. 카드 시각 영역은 "{상대 시간} · {한국 시간}"이며, 마우스를 올리면 "2026년 9월 30일 수요일 14:57"처럼 보인다.
  - 하이드레이션 경고 억제는 상대 시간 부분에만 둔다. 정확한 시각은 한국 시간으로 고정되어 서버와 브라우저가 같은 문자열을 그린다.
  - 서버를 `TZ=UTC`로 띄워(Vercel과 같은 조건) 렌더링해도 "9월 30일 14:57"(한국 시간)이 나오는 것을 확인했다.
  - 좁은 카드에서는 정확한 시각 부분이 통째로 줄바꿈된다. 모바일 화면 확인은 05번 티켓에서 한다.
