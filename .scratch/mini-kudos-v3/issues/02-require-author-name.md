# 02: 이름 필수 입력

**What to build:** Author가 작성 폼에서 "이름" 칸을 보고, 비우거나 공백만 넣고 제출하면 이름 칸 아래에서 "이름을 입력해 주세요"를 본다. 이름·메시지·비밀번호를 모두 넣으면 글이 목록 맨 위에 나타난다. 이름이 선택 입력이던 때 "익명"으로 남은 글은 그대로 보이고, 비밀번호로 수정·삭제할 수 있다.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [ ] 작성 API: 이름 누락·빈 문자열·공백만이면 400 `VALIDATION_FAILED`이고 `fieldErrors.author`가 "이름을 입력해 주세요"다. 이름이 있으면 201이다
- [ ] 서버의 "익명" 기본값 처리가 없다. DB 컬럼 기본값·제약은 그대로이고 마이그레이션은 없다
- [ ] 클라이언트 폼도 같은 공용 스키마로 이름 누락을 막는다
- [ ] 작성 폼 라벨이 "이름", placeholder가 "예: 다은"이다. 수정 폼의 이름 칸은 지금처럼 비활성화되어 기존 값을 보여준다
- [ ] 기존 "익명" Kudo를 수정·삭제할 수 있다(수정 검증은 이름을 받지 않는다)
- [ ] 시드의 "익명" 작성자 예시가 실제 이름으로 바뀐다
- [ ] Route Handler 테스트: 이름 누락·빈 값·공백만 400과 필드 오류, "빈 작성자는 익명"을 기대하던 기존 테스트를 새 규칙으로 교체
- [ ] 수동 확인: 이름을 비우고 제출했을 때 칸 아래 안내

## Comments
