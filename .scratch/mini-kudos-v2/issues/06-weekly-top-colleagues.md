# 06: 이번 주 가장 따뜻한 동료 (Top 3)

**What to build:** Visitor는 목록 위에서 "이번 주 가장 따뜻한 동료"로 최근 7일 동안 Colleague Temperature(동료 온도)가 가장 높은 받는 사람 3명을 🥇🥈🥉, 이름, 온도 배지와 함께 본다. 누르면 그 사람 모아보기로 바뀌고(다시 누르면 해제), 지금 모아 보고 있는 사람은 강조된다. 카테고리·검색·정렬과 상관없이 항상 보드 전체 기준이며, 리액션을 누르거나 Kudo를 남기면 갱신된다. 최근 7일 동안 Kudo를 받은 사람이 없으면 영역이 숨겨진다.

**Blocked by:** 03 (받는 사람별 모아보기)

**Status:** resolved

- [ ] 동료 온도 순수 함수: min(99.9, 36.5 + 0.2 × 받은 Kudo 수 + 0.1 × 리액션 수), 소수 첫째 자리 반올림. 단위 테스트(공식, 상한, 반올림)
- [ ] Board 통계 응답에 `topColleagues: { name, kudoCount, reactionCount, temperature }[]`(0~3개)가 있다
- [ ] 최근 7일(168시간) 안에 작성된 Kudo만 세고, 리액션은 그 Kudo들에 달린 전체 수다. 받는 사람 없는 Kudo는 제외한다
- [ ] 받는 사람은 공백 제거·소문자 기준으로 묶고, 표시 이름은 가장 최근 Kudo의 표기다
- [ ] 정렬: 동료 온도 desc, 동점이면 가장 최근에 받은 Kudo의 작성 시각 desc. 최대 3명
- [ ] Route Handler 테스트: 순위·동점 처리·이름 표기 합산과 최근 표기·받는 사람 없음 제외·7일 밖 제외(테스트 준비 단계에서만 DB로 작성 시각 조정)·빈 배열
- [ ] 필터 영역 위에 Top 3 영역이 있고, 누르면 `to` 조건 설정·해제, 현재 `to`와 같은 사람 강조, 비면 숨김
- [ ] 리액션·작성·수정·삭제 뒤 보드 통계를 다시 불러오는 기존 규칙으로 Top 3도 갱신된다
- [ ] 수동 확인: 리액션을 눌러 순위가 바뀌는지, 칩 클릭으로 모아보기 설정·해제
