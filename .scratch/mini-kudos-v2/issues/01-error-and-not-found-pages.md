# 01: 오류·404 화면

**What to build:** Visitor가 없는 주소로 들어오면 "페이지를 찾을 수 없어요" 안내와 "보드로 가기" 버튼을 본다. 예상치 못한 오류가 나면 "문제가 생겼어요" 안내와 다시 시도 버튼, 보드로 가기 링크를 본다. 두 화면 모두 헤더·스타일·다크 모드를 그대로 따르며, 오류 내용은 화면에 드러내지 않는다.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [ ] 없는 주소(예: `/없는-주소`)에서 한국어 404 화면이 보이고 HTTP 상태는 404다
- [ ] 404 화면은 문구를 바꿔 재사용할 수 있다(04번 티켓의 "이미 삭제되었거나 없는 Kudo예요")
- [ ] 렌더링 중 오류가 나면 앱 전체 오류 화면이 보이고, 다시 시도 버튼이 오류 경계를 재설정한다
- [ ] 두 화면 모두 루트 레이아웃 안에서 그려져 헤더와 다크 모드를 따른다
- [ ] `npm run build`와 `npm run lint`가 통과한다
- [ ] 수동 확인: 라이트·다크 모드에서 404 화면, 오류를 일부러 낸 상태에서 오류 화면과 다시 시도
