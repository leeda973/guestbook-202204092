# 02: 카드 순서 개선 (열 분배)

**What to build:** Visitor가 보드를 보면 쿠도 카드가 왼쪽→오른쪽, 위→아래 순서로 놓여, 인기순 1·2·3위가 첫 줄에 나란히 보인다. 높이가 제각각인 포스트잇 배치는 그대로이고, 화면 폭에 따라 1·2·3열로 바뀌어도 순서가 유지된다.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [ ] 카드를 열 수 n에 맞춰 차례로 나눠 담는 순수 함수가 있다(i번째 카드 → i mod n번째 열)
- [ ] 순수 함수 단위 테스트: n=1·2·3, 카드 수가 열 수보다 적을 때, 빈 목록
- [ ] 열 수는 768px 미만 1열, 1024px 미만 2열, 그 이상 3열이다. 서버 렌더와 첫 화면은 1열이고, 브라우저에서 폭을 확인한 뒤 한 번 다시 배치한다
- [ ] 무한 스크롤로 페이지가 붙어도 순서가 이어진다
- [ ] 수동 확인: 인기순에서 첫 줄이 1·2·3위, 창 폭을 바꿨을 때 열 수와 순서

## Comments

- 2026-09-29: 구현 완료. 열 분배 순수 함수와 테스트 5개(3열·2열·1열, 카드가 열보다 적을 때, 빈 목록) 통과. 보드는 CSS columns 대신 열 수만큼 세로 묶음을 두고 카드를 차례로 나눠 담는다. 열 수는 화면 폭 미디어 쿼리로 정하며 서버 렌더는 1열이다. 브라우저에서 인기순 첫 줄이 1·2·3위(42.0°, 42.0°, 41.5°)로 나란히 놓이는 것을 확인했다. 로딩 스켈레톤은 순서가 없으므로 CSS columns를 그대로 둔다.
