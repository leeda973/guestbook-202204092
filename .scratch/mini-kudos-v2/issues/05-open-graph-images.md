# 05: 미리보기 이미지 (OG)

**What to build:** Author가 Kudo Page 주소를 메신저에 붙여넣으면 그 Kudo 모양의 미리보기 이미지가 뜬다(카테고리 색 배경, 카테고리 라벨, 메시지, To·From, 쿠도 온도, "Mini Kudos" 로고). 보드 메인 주소를 공유하면 로고·슬로건·보드 온도가 담긴 기본 이미지가 뜬다. 한글이 깨지지 않으며, 폰트를 받지 못하거나 삭제된 Kudo라도 기본 이미지로 대신해 미리보기가 깨지지 않는다.

**Blocked by:** 04 (Kudo Page와 공유 버튼)

**Status:** resolved

- [ ] Kudo Page 이미지(1200×630 PNG): 카테고리 색, 라벨, 메시지(보이는 글자 80자에서 "…"), To(있을 때)·From, 쿠도 온도, 로고
- [ ] 보드 기본 이미지(1200×630 PNG): 로고, 슬로건, 현재 보드 온도
- [ ] 한글 폰트는 Google Fonts Noto Sans KR에서 이미지에 들어갈 글자만 요청해 받는다
- [ ] 폰트 요청 실패, Kudo 없음, DB 조회 실패 시 오류 대신 로고만 있는 기본 이미지를 돌려준다
- [ ] 페이지 HTML에 `og:image`가 절대 주소로 들어간다
- [ ] 수동 확인: 실행 중인 앱에서 두 이미지 주소가 200과 `image/png`를 돌려주고, 브라우저로 열어 모양·한글 확인. 없는 Kudo의 이미지가 기본 이미지인지 확인

## Comments

- 2026-09-29: 구현 완료. Kudo Page 이미지와 보드 기본 이미지(요청 시점의 보드 온도)를 만들었다. 실행 중인 앱에서 두 이미지 주소가 200과 `image/png`를 돌려주고, `og:image`가 절대 주소로 들어가는 것을 확인했다. 이미지를 직접 열어 한글·카테고리 색·온도 색 구간·이모지(Twemoji)를 확인했고, 없는 Kudo는 로고만 있는 기본 이미지가 나온다.
  - 확인 중 고친 것: 한글이 단어 중간에서 줄바꿈되어 `word-break: keep-all`을 적용했다.
  - 이미지 렌더러가 CSS 변수와 oklch를 모르므로 카테고리·온도 색은 라이트 모드 토큰과 같은 톤의 hex로 따로 두었다.
  - 폰트 요청 실패 시의 대체 경로는 코드로만 확인했다(실제 네트워크 실패를 재현하지는 않았다). 없는 Kudo 경로로 같은 기본 이미지 함수가 동작하는 것은 확인했다.
